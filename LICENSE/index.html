    TNFR Python Engine¶

    This software implements Resonant Fractal Nature Theory (TNFR), a computational framework for modeling coherent patterns through resonance dynamics.

    Project: TNFR-Python-Engine
    Repository: https://github.com/fermga/TNFR-Python-Engine
    PyPI: https://pypi.org/project/tnfr/
    DOI: 10.5281/zenodo.17602860
