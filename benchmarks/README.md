# TNFR benchmark guide

Benchmarks are instruments, not a second research plan. Consult the
[theory index](../theory/README.md) for claim status and the
[execution plan](../theory/research/FIVE_STAGE_EXECUTION_PLAN.md#current-g3-gate)
for the active queue. A filename containing `emergent`, `conservation`,
`unification` or `universality` does not establish that claim.

## Reuse the mechanism appropriate to the question

- [Local relational composition](relational_local_composition.py) checks exact
  rational matrices for one fixed regional/port observation through the shared
  invariant-row kernel. Run `python -m benchmarks.relational_local_composition`
  for its declared `c=inverse_pi=1/3` algebra probe. These are not the actual
  irrational coefficients: the [analytic rank and nonlinear boundary](../theory/nodal/RELATIONAL_PATTERN_COMPOSITION.md)
  have a separate proof. No trajectory, coefficient fit or physical node is
  inferred from its rank sequence `(6,10,10)`.
  Its state-and-rate obstruction probe also checks equal coarse observations
  and rates with different accelerations at the fixed phase lock. Rational
  sine/cosine inputs define an algebraic family, not physical calibration or
  exact trigonometric admission. Static native controls test implementation.
  `analyze_local_memory` reuses the same matrices for the complete 10-visible,
  8-hidden split and its quadratic energy identities. The
  [joint-memory owner](../theory/nodal/RELATIONAL_PATTERN_MEMORY.md) supplies
  nonlinear scope, existing-study reuse and conditional approximation bounds;
  the algebra probe supplies no numerical remainder certificate.
- [Derived memory prediction](relational_memory_prediction.py) advances analytic
  amplitude coefficients on the shared Euler arithmetic. The
  [reserved response](relational_memory_response.py) compares one preparation
  with the full engine on three matched grids, including a direct-cubic control
  without hidden feedback. [Results and limits](../theory/nodal/RELATIONAL_PATTERN_MEMORY.md#reserved-memory-response)
  distinguish finite prediction advantage from continuous-time error. Use
  `python -m benchmarks.relational_memory_response --prepare --output artifacts/memory/result.json`
  and then the same command without `--prepare` for a current-source regression.
  Preparation archives all package Python sources and freezes the forecasts;
  never replace the retained first response in `docs/assets/`.
- Use the shared [scale bridge](../theory/TNFR_SCALE_GEOMETRY_AND_BRIDGE.md) and
  [memory owner](../theory/DERIVED_EPI_MEMORY.md) for closure or hidden-state
  questions. Spectral analogies do not replace their exact admission criteria.
- Use the retained-record THOL audits when the required evidence already exists.
  A producer can regenerate a different causal run; validating an existing
  record's contents is a different operation. A content hash does not establish
  the identity of a producer or the truth of declared acquisition conditions.
- [Wave/particle comparisons](emergent_wave_particle_correspondence.py) retain
  declared graph-wave models and negative controls. Supplied waves, standing
  modes or winding numbers do not by themselves identify physical particles.
- `emergent_simplex_dimension.py`, `emergent_fractal_simplex_dimension.py` and
  `emergent_generation_count.py` retain useful graph/spectral comparisons. Their
  clique size, gluing, scale ratio or potential well are inputs. They do not
  select physical dimension or particle generations.

The retired particle/shell, chemical lookup and PDE recipe producers added
potential wells, screening, shell order or fluid equations without deriving
those laws from the nodal product. Shared graph waves, diffusion and winding
remain available through their mathematical owners; removing the unsupported
identifications does not retire those scoped calculations.
The [scope record](../theory/research/archive/README.md#foundation-reassessment-2026-09-20)
owns the retirement list and API migrations.

The obsolete magnitude-only, out-of-range curvature-zone and orphan timing-
clustering campaigns are removed. Timing clusters and in-sample field
correlations do not establish physical universality or held-out prediction.
The legacy fast coherence-length sweep is also retired: its nominal intensity
never entered preparation or dynamics, so repairing its obsolete API calls
would not make the comparison an intensity-response experiment.
The unused universality aggregator, integrated force-regime producer and
nodal-position/prime comparison are also retired. Their missing-data pairing,
invented events, cancelling scores or disconnected supplied formulas did not
provide a predictive nodal study. Use shared study execution and diagnostics
for actual operator responses; retained winding, graph-wave and arithmetic
comparisons keep their explicit auxiliary scope.
Current form and field-domain controls are the
[signed-form admission tests](../tests/test_nodal_solver_epi_scope.py),
[storage/entropy scope tests](../tests/test_epi_type_signature_scope.py),
[wrapped tetrad bounds](../tests/physics/test_tetrad_bounds.py) and
[circular-resultant controls](../tests/physics/test_phase_curvature_resultant.py).
The corresponding definitions live in the
[form foundations](../theory/FUNDAMENTAL_THEORY.md) and field owner linked above.

## Running and reporting

The capacity-intervention instrument freezes its finite-response hypotheses
before running either law. Use a fresh output pair for a current-source replay:

```bash
python benchmarks/relational_capacity_response.py --prepare --output artifacts/relational-capacity/result.json
python benchmarks/relational_capacity_response.py --output artifacts/relational-capacity/result.json
```

It uses the production relational step and a benchmark-only countermodel,
retains actual balance defects and tests three step sizes. Step refinement
is empirical numerical evidence, not an exact-flow error enclosure. Failed
admission or a failed frozen decision is retained without overwriting records.

For consolidation, use `python benchmarks/relational_capacity_audit.py` to
inspect the retained prediction and response without advancing any state.
The audit distinguishes record consistency, the frozen numerical verdict and
compatibility with the currently installed source/runtime. Three checkpoints
per trace cannot independently authenticate every omitted step, extrema or
the continuous-time integral. Source hashes identify listed file contents;
they do not prove physical acquisition or the chronology of execution.
Exact snapshot replay agreement is a separate result: the first manifest
does not record every platform or mathematical-library detail.

The frozen producer's Python `evaluate_prediction` entry point expects the
native mapping returned by `prepare_prediction`, including its `Fraction`
values. It is not a raw JSON deserializer. Use the CLI for preparation and
evaluation, and the audit's exact JSON loader for read-only retained records.

For the distinct local-recovery control, freeze a fresh output pair before
executing its two grids:

```bash
python benchmarks/relational_local_recovery.py --prepare --output artifacts/relational-recovery/result.json
python benchmarks/relational_local_recovery.py --output artifacts/relational-recovery/result.json
```

Its [first retained response](../docs/assets/relational_local_recovery/result.json)
uses the existing production joint step. The experiment measures centered
form and phase deviations from a supplied C5 twist, retains moving common
offsets, and includes an inactive zero-capacity boundary. Two-grid agreement
is a finite numerical check, not an exact-flow error certificate or a claim
that the winding was generated autonomously. Research tests reuse the saved
record instead of rerunning its trajectories for each assertion.

The corresponding paired-region response has its own finite prediction:

```bash
python benchmarks/relational_region_interaction.py --prepare --output artifacts/relational-interaction/result.json
python benchmarks/relational_region_interaction.py --output artifacts/relational-interaction/result.json
```

It compares joined support with separately executed disconnected rings,
reusing native phase forcing and the full-graph regional balance observer.
The [retained response](../docs/assets/relational_region_interaction/result.json)
and [theory](../theory/nodal/RELATIONAL_EXCHANGE_ADMISSION.md#relational-region-interaction)
distinguish initial derivative identities, finite transmission, numerical
refinement and the information discarded by regional means/storage.

The wider-domain sector-crossing control also requires a separately frozen
prediction before execution:

```bash
python benchmarks/relational_formation_response.py --prepare --output artifacts/relational-formation/result.json
python benchmarks/relational_formation_response.py --output artifacts/relational-formation/result.json
```

It requires the workspace package (editable install or `PYTHONPATH=src`),
records all package source fingerprints, and stops each of three fixed grids
at its first shared-owner rejection without retry. The
[retained response](../docs/assets/relational_formation_response/result.json)
passes the short winding prediction but stops before its horizon; final capture
is unavailable. Tests reuse its checkpoints without regenerating the campaign.

The distinct upper-corner preparation uses the same evolution owner and the
two shared endpoint certificates:

```bash
python benchmarks/relational_capture_response.py --prepare --output artifacts/relational-capture/result.json
python benchmarks/relational_capture_response.py --output artifacts/relational-capture/result.json
```

One state, three grids, a fixed horizon and checkpoint stopping rules are
frozen before evaluation. An admitted endpoint ends that grid; otherwise it
stops at the first engine rejection or the horizon. It never projects
symmetry, changes the phase law or retries. The
[retained record](../docs/assets/relational_capture_response/result.json)
separates observed winding, ideal endpoint capture and unavailable bounds.
The [theoretical owner](../theory/nodal/RELATIONAL_EXCHANGE_ADMISSION.md#relational-upper-corner-preparation)
contains the analytic short-crossing proof and the finite response's scope.
Grid differences are numerical evidence, not an exact ODE-error enclosure.

The later acute-sector theorem is assessed separately, without evolution:

```bash
python benchmarks/relational_capture_audit.py --output artifacts/relational-capture/endpoint-audit.json
```

This read-only audit binds the immutable prediction/response hashes and
applies the new theorem to the actual retained endpoints. Its
[separate report](../docs/assets/relational_capture_response/endpoint-capture.audit.json)
does not change the original failed capture-gate verdict. The
[source-at-evaluation archive](../docs/assets/relational_capture_response/source-at-evaluation.zip)
preserves all 599 original fingerprinted files; later engine/SDK integration
changes the working source manifest honestly. The source archive contains
code only; dependency versions remain recorded in the prediction.
The [four-file overlay](../docs/assets/relational_capture_response/source-at-endpoint-audit.delta.zip)
combined with that base archive preserves the later endpoint audit's exact
source before the sector certificate's capacity/beta generalization. Current
read-only replays can have a richer report schema while the original record
and its source remain unchanged.

The validated continuous audit has its own freeze/evaluate path:

```bash
python -m benchmarks.relational_transit_proof --prepare --output artifacts/relational-capture/transit.json
python -m benchmarks.relational_transit_proof --output artifacts/relational-capture/transit.json
```

Run from the repository root with `PYTHONPATH=src`. Preparation writes an
exclusive sibling `.protocol.json` and `.source.zip`; evaluation requires
the unchanged inputs, source and runtime. This is a post-evaluation proof
audit of the original continuous IVP, not a new reserved experiment.
The [retained report](../docs/assets/relational_capture_response/continuous-transit.audit.json)
contains all 256 accepted whole-time tubes and the successful whole-endpoint
capture bound. The original finite prediction remains false. The companion
[protocol](../docs/assets/relational_capture_response/continuous-transit.audit.protocol.json)
and [source archive](../docs/assets/relational_capture_response/continuous-transit.audit.source.zip)
bind exact represented inputs and all executed package/producer files.
Routine tests check kernels, short reference solutions and retained witnesses;
they do not rerun the full proof computation.

The same instrument also freezes the prospective zero-form control against
that immutable continuous reference:

```bash
python -m benchmarks.relational_transit_proof --zero-form --prepare --output artifacts/relational-zero-form/result.json
python -m benchmarks.relational_transit_proof --zero-form --output artifacts/relational-zero-form/result.json
```

Only the initial form is removed; phase, support, capacity, law and temporal
policy are retained. All three protected terminal basins are admitted as
competing outcomes. The [first response](../docs/assets/relational_zero_form_response/result.json)
proves consensus capture; transient winding in saved endpoints is a separate
post-evaluation observation. Its [protocol](../docs/assets/relational_zero_form_response/result.protocol.json)
and [source archive](../docs/assets/relational_zero_form_response/result.source.zip)
preserve the first evaluation. A false positive-pattern flag together with
`terminal_basin_admitted=true` and `target_sector=0` is an informative consensus
result, not numerical failure. The shared initial derivative calculation is
static and does not preselect a future basin. See the
[mechanism and scope](../theory/nodal/RELATIONAL_EXCHANGE_ADMISSION.md#relational-zero-form-control).

The mutually exclusive equal-storage control instead negates the reference
form while retaining phases and every model/temporal input:

```bash
python -m benchmarks.relational_transit_proof --reverse-form --prepare --output artifacts/relational-reversed-form/result.json
python -m benchmarks.relational_transit_proof --reverse-form --output artifacts/relational-reversed-form/result.json
```

Preparation checks exact initial storage/loss equality and reversed phase
velocity through the reduced law and fresh native engine fields. Signed
exchange and energy-curvature intervals are static deductions, not a selected
terminal prediction. The three-basin criterion is unchanged. A different
certified limit sets `initial_storage_selector_refuted=true`; the same limit
does not establish storage sufficiency, and unavailable evidence yields
`null`. See the [derivation](../theory/nodal/RELATIONAL_EXCHANGE_ADMISSION.md#relational-reversed-form-control).
The [first retained response](../docs/assets/relational_reversed_form_response/result.json)
certifies consensus, distinct from the reference's positive twist despite
equal initial storage and loss. Its [protocol](../docs/assets/relational_reversed_form_response/result.protocol.json)
and [source archive](../docs/assets/relational_reversed_form_response/result.source.zip)
bind the evaluation. Winding zero over the entire retained interval is a
separate retrospective inference from its whole-time tubes.

Install the repository in editable mode, then choose one instrument whose
assumptions and dependencies match the task:

```bash
python -m pip install -e ".[dev-minimal]"
python benchmarks/directed_nonnormal_dynamics.py
```

Use `--help` only where the script exposes a CLI. Optional libraries and retained
artifacts differ by instrument; do not assume every script runs after the same
minimal installation. This directory is not a batch execution manifest.

The F4 response instrument separates preparation from evaluation:

```bash
python benchmarks/source_relative_form_response.py --prepare --output artifacts/f4/result.json
python benchmarks/source_relative_form_response.py --output artifacts/f4/result.json
```

Preparation writes a sibling `result.prediction.json` before evolving the
engine. Evaluation requires an exact match to that frozen specification and
its source/runtime fingerprints. A different specification cannot silently
overwrite the retained prediction. Use a new output path for an explicitly
revised study; replaying the existing protocol is a regression, not new
reserved evidence. Exact fractions are serialized as numerator/denominator
objects. The theoretical owner above retains the first evaluated records.

Keep those first prediction/response files immutable. The current runner
refuses to replace an existing response and records failed decisions with a
nonzero exit status. Its scientific admission remains active under `python -O`.
Use a fresh path under `artifacts/` for every replay instead of targeting
retained `docs/assets/` records. A changed Python/dependency version, source
edit or source line ending can fail the strict byte-fingerprint comparison
even when the mathematics is
unchanged. Prepare a separate current-source regression pair in that case;
retain and compare the old record rather than replacing its fingerprints or
describing the new run as the first reserved evaluation. The listed source
fingerprints bind those files, not an entire transitive dependency archive.
The exact [original producer](../docs/assets/source_relative_form_response/producer.v1.py.txt)
is retained with SHA-256
`2728f39f078b02fd6912d2efa708d843c84b55a9b402cfefd5f5a728aa4637cd`,
matching its entry in the first prediction. That evaluated runner relied on
Python assertions and required ordinary execution. The maintained v2 runner
enforces the same scientific boundaries explicitly; it is a regression of
the evaluated preparation, not a second reserved experiment.
The original producer and both frozen JSON records have explicit Git `-text`
attributes so checkout line-ending conversion cannot change their byte hashes.

The conditional exchange comparison uses the same separate freeze/evaluate
workflow, but executes **prepared constitutive probes**, not a trajectory:

```bash
python benchmarks/phase_form_exchange_comparison.py --prepare --output artifacts/exchange/result.json
python benchmarks/phase_form_exchange_comparison.py --output artifacts/exchange/result.json
```

Its prospective inputs match one mode's response scale before evaluating the
second. Native pressure is evaluated on each law's supplied tangent direction;
the cotangent term is eliminated analytically only in the admitted projection.
The runner checks the `fused_canonical` execution path, represented-input
defects and frozen decision intervals. It refuses protocol changes or retained
file replacement and records failed evaluations. Its source fingerprints
cover listed files, not the entire dependency tree. The first records linked
from its theory owner are immutable; later runs are regressions.

A reusable record identifies the revision, environment/backend, graph and source
construction, parameters, seed, explicit laws or operator sequence, raw artifact
and hash. Include the available state/field observations and their provenance;
pure algebraic or timing instruments need not invent a trajectory or tetrad.
For data comparisons, separate calibration from evaluation and disclose supplied
labels, known factors and retrospective reconstruction.

Compare performance on identical inputs, semantics and warm-up policy. Report
absolute times alongside ratios. A finite benchmark supports only its measured
domain and does not establish a universal speedup, canonical threshold, general
stability theorem or physical law.
