    Recover a recorded blob with git cat-file blob <git_blob> and write its returned bytes using a binary-safe writer. Shell text redirection may change encoding or line endings. An immutable Git file URL is convenient for reading; blob identity and SHA-256 establish byte-level recovery. A manifest is a receipt, not evidence that its former claims are correct. The cleanup records include uncommitted edits for consolidated working copies; Git alone would not recover those bytes. Apply any declared newline conversion first, then the recorded edits in descending byte-offset order, and verify the working-copy hash. Useful content remains with the stated current owners.

    Retained boundaries and replacements¶

    • The theory catalog owns definitions/proof routes; the documentation map owns usage and contract routes. Former navigation catalogs and per-turn delivery logs are recovered from the manifests, not maintained as additional authorities.
    • Retired particle/chemistry, Yang-Mills and Navier-Stokes mappings had supplied external assumptions, not a derived nodal bridge. Their useful limits remain in retired-programme boundaries. Shared graph, winding, symmetry and evidence kernels retain their explicit premises.
    • Removed APIs have no alias silently substituting a different model. Exact former names and implementation bytes remain in the foundation manifest. Current public interfaces belong to the API contracts.
    • Duplicate conservation comparisons do not replace the trajectory-balance owner. Arithmetic/spectral claims retain the Riemann scope.
    • Reported interface observations preserve their data/model limitations. Moving or retiring a narrative does not rerun the experiment or establish physical validation.
    • Benchmark and example catalogs identify maintained instruments. Frozen protocols, source archives, responses and verdicts remain unchanged at their recorded paths.
