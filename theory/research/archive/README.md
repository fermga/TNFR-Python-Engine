owns the current question and priorities. Old plan, strategy and portfolio
paths are generated compatibility routes, not active instructions.

recovery records. Use the [theory catalog](../../README.md) for current
definitions and mathematical capabilities. Historical instructions, milestone
labels and reported successes are not current authority.

Recover a recorded blob with `git cat-file blob <git_blob>` and write its
returned bytes using a binary-safe writer. Shell text redirection may change
encoding or line endings. An immutable Git file URL is convenient for reading;
blob identity and SHA-256 establish byte-level recovery. A manifest is a receipt,
not evidence that its former claims are correct.
The cleanup records include uncommitted edits for consolidated working copies;
Git alone would not recover those bytes. Apply any declared newline conversion
first, then the recorded edits in descending byte-offset order, and verify the
working-copy hash. Useful content remains with the stated current owners.
