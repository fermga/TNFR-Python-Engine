# Native operator dynamics

This owner develops conditional collective descriptions of the general native
operator runtime: fresh pressure and diagnostics, configured selection, live
grammar, ordered direct glyphs, numerical integration and subsequent policies.
The admitted source, complete law, consumed memory and structural clock remain
explicit in each result. Restricted closure does not establish autonomous
occurrence, formed collective identity or physical identification.

The [structural operator contracts](STRUCTURAL_OPERATORS.md),
[collective action criterion](STRUCTURAL_OPERATORS.md#collective-operator-descent)
and [ordered-language descent](STRUCTURAL_OPERATORS.md#collective-grammar-descent)
own the underlying event and grammar obligations. The
[research program](RESEARCH_PROGRAM.md#research-current-question) remains
the sole research queue.

The [conditional collective calculus](NATIVE_COLLECTIVE_CALCULUS.md#native-collective-calculus) combines the
five admitted event/flow maps below and states their shared memory and branch
obligations. Its [finite retention criterion](NATIVE_COLLECTIVE_CALCULUS.md#native-transverse-retention)
adds explicit selection/admission margins for unequal forms. These are partial
mathematical descriptions, not new execution paths.
The [joint form/capacity extension](NATIVE_COLLECTIVE_CALCULUS.md#native-joint-collective-calculus) retains
the additional association consumed after unequal-capacity adaptation.

### Native selector memory and realized occurrence

The [native selector controls](../tests/operators/test_nfr_selector_occurrence.py)
use the existing ten-node doubled-C5 support: each adjacent pair of two-member
blocks has all four unit links. Every node has signed form `x=1/4`, capacity
one, phase zero and freshly computed pressure zero. Fresh native `Si>0.9`
makes the actual `DefaultGlyphSelector` propose Coherence (IL) everywhere. The declared
primitive batch path, topology/node order, seed, live grammar and structural
clock `t=1` are identical in the comparison. No continuous sine trajectory or
phase coordinator runs; the pair-state reader supplies coordinates only.

Retain the supplied `AL → IL → EN` grammar context, including persistent debt
and prior Coherence after bounded-trace eviction. All Reception lag counts
start at zero.
Change only node 0's pre-batch `since_AL` from zero to the default limit five.
The actual native batch increments lag counts before testing the strict limit:
one source executes Coherence at every node; the other executes Emission (AL)
at node 0 and Coherence elsewhere. Live admission passes both requests.
Thus identical instantaneous nodal coordinates, pair coordinates and base proposals do not
determine the realized mark when supplied selector memory is discarded.

Let `d` be the actual represented positive Emission increment at node 0. The
default boost keeps its form strictly inside the clamp interval. Coherence
leaves this zero-pressure source's physical coordinates unchanged. Emission
changes the first pair's form mean by `d/2` and its squared internal form by `(d/2)^2`; other
pairs retain their coordinates. These are exact identities for the represented
endpoint values, not continuous-rate predictions. The structural clock stays
at one. The histories and counters are admitted supplied state, not a proof
that the declared continuous law acquired them.

A control changes persistent U2 debt from zero to two while retaining the
same physical state and bounded trace. Both sources still execute Coherence: their
successor debts are zero and one. Different eligibility information therefore
need not cause different realized actions. This distinguishes the new actual
selector witness from an admission-only counterexample.

**Restricted sufficient policy memory.** Suppose every base proposal is Coherence,
the proposed Emission, Reception (EN) and Coherence actions pass live admission,
no execution fails, and
lag limits `L,E` are fixed nonnegative integers. For pre-batch counts `a,e`,
the implemented priority and successor counters are

```text
mark = AL if a >= L, else EN if e >= E, else IL
AL: (a,e) -> (0, min(e+1,E))
EN: (a,e) -> (a+1, 0)
IL: (a,e) -> (a+1, e+1).
```

After projecting the successor counts too, `(min(a,L), min(e,E))` closes
this finite counter/mark system. Indeed, all threshold decisions and capped
successors depend only on those capped counts. This does not close the whole
NFR state, prove minimal memory, or remove context and target associations.
When grammar replaces a proposal, bookkeeping follows the action actually
executed; the displayed recurrence applies only on its admitted branch.

One current eligibility bit is insufficient for repeated decisions. With
the same explicit Reception limit eight, sources starting with Emission counts
zero and one both execute Coherence for four batches, then Coherence and Emission
on the fifth. The controls refresh the actual pressure and sense index before
each decision and verify the common Coherence proposals. Counts measure selector
batches, not elapsed structural time. A schedule linking decisions to time
is an additional part of a complete hybrid law.

This result identifies consumed memory in an existing supplied controller.
It does not derive the controller, its lag limits or Emission's form increment from
the nodal identity. In particular, it does not transfer the closed sine law's
conserved form to this hybrid path or establish physical particle formation.

### Decision schedule and structural time

When `apply_glyphs=True`, the native runtime executes one selector batch at each
outer invocation's left boundary, after pressure and optional sense-index
refresh and before the nodal integrator. Its internal integration substeps do
not request more operators.
Thus a complete hybrid model includes the decision schedule as well as the
state, selector, grammar context and continuous rows. The operator-step index,
lag counters, runtime invocation ordinal and structural clock have different
meanings; none can be reconstructed from another without additional premises.

The [actual runtime controls](../tests/operators/test_nfr_selector_occurrence.py)
reuse the uniform doubled-C5 source above, with all lag counters zero, Euler
integration and no Gamma. Default phase/capacity policies remain enabled;
uniform phase zero and capacity one are fixed by their actual updates. Default
limits are five batches for Emission (AL) and three for Reception (EN).
The supplied context admits Coherence (IL), Reception and Emission. No auxiliary
math engine or scientific callback is supplied; the automatic network REMESH
gate's default 25-sample stability window does not activate during this six-call
comparison. That gate differs from the node Recursivity advisory.

Before Emission, Coherence preserves zero pressure and Reception preserves
uniform form. Every unforced default base choice is therefore Coherence, while
the lag policy realizes the six-batch word `IL → IL → IL → EN → IL → AL`.
The final Emission acts on every node, leaving form uniform and stored pressure
zero. A fresh evaluation of the default pressure law would also give zero;
the runtime does not perform that refresh after the final Emission. Let `d>0`
be its represented increment, as admitted above. Starting from structural time
one gives the following exact finite comparison:

| Supplied execution | Realized operator events | Final time | Final uniform form |
| --- | --- | --- | --- |
| Three outer calls of duration `1/4` | Coherence at `1,5/4,3/2` | `7/4` | `1/4` |
| Six outer calls of duration `1/8` | Coherence at `1,9/8,5/4`; Reception at `11/8`; Coherence at `3/2`; Emission at `13/8` | `7/4` | `1/4+d` |
| Three outer calls of duration `1/4`, each internally split into two integration intervals | Same three Coherence events as the first row | `7/4` | `1/4` |

The represented increments and these dyadic clock sums are checked directly.
The discrepancy cannot be assigned to integration error: the form row is zero
between events in this source, and the native phase/capacity updates preserve
their uniform values. Outer-call refinement has changed the supplied hybrid
event schedule. Internal integration refinement retains that schedule here;
this control does not prove convergence for arbitrary nonuniform source laws.

Restricting the six finer calls to select operators only at the three original
decision times preserves the marks, lag counts and physical endpoint on this
source. It does not preserve all runtime state: stability counters and phase
telemetry advance three versus six times. Similarly, six calls with `dt=0`
execute the six-batch word at structural time one and produce the same uniform
Emission increment. A zero flow duration is not a request for zero hybrid events.

**Consequence.** The native batch policy is a supplied sampled controller,
not a clock-independent occurrence law derived from the continuous nodal row.
A prospective comparison must freeze event times and every per-call policy,
or justify how they transform when the clock or decision schedule changes.
The existing [explicit event-schedule contract](../docs/contracts/OPERATOR_EVENTS.md)
and [flow-refinement controls](../tests/physics/test_runtime_flow_refinement.py)
provide reusable methods for fixed events. Their executor, pressure-refresh and
admission premises remain distinct from the complete native runtime. The
[runtime ordinal contract](../src/tnfr/_runtime_steps.py) records invocation
identity, including partial failures; it does not solve occurrence selection.

**Source and law.** Take two disconnected unit-weight edges `(0,1)` and `(2,3)`,

ceiling `2*pi`. Both preparations retain structural time one, seed 17, supplied
`Emission → Coherence → Reception` context, zero Emission/Reception lag counts,
and constant two-sample form evidence at times `3/4` and `1`. These histories
are admitted preparation, not a reconstruction of earlier executed operators.

Let `a` denote the effective phase-pressure coefficient and `(alpha,beta,gamma)`
the normalized Sense Index weights. Their default numerical coincidences are
configured choices. The [mixed pressure law](NODAL_PARAMETER_FOUNDATIONS.md#21-the-implemented-pressure-is-a-specified-relational-map)

```text
p_local = (3*a/4, -3*a/4),       p_remote = (0,0),
Vmax = M,                       Pmax = max |p| = 3*a/4,
Si_local(M) = alpha/M + beta/4.                         (M >= 1)
```

Thus fresh local pressure and unforced form rates `nu*p` agree between the
preparations. Only the capacity maximum in this diagnostic changes. The
represented scalar and vector Si controls give the following separated branches:

| Remote capacities | Local Si | Actual local operator | Stored pressure magnitude immediately after the event |
| --- | --- | --- | --- |
| `(1,1)` | approximately `0.8043353561` | Coherence (IL) | approximately `0.4315451554` |
| `(4,4)` | approximately `0.2354251114` | Dissonance (OZ) | approximately `0.75` |

The configured upper/lower Si cuts are `1/2` and `1/4`; normalized pressure one
exceeds the Dissonance branch's `0.133` cut. Both actions pass the same live
grammar, and no lag forces another request. Their direct glyph maps multiply
the nonzero pressure by the admitted factors `h<1` and `f>1`, respectively.
The opposite pressure signs are retained. This is a difference in executed
state changes, not merely in proposed names or a Mutation eligibility test.

**Execution boundary.** One native Euler call with `dt=0`, Gamma absent, fresh
pressure/Si and strict grammar records each actual glyph before and after its

runs. Direct glyphs, rather than public operator classes, own these events.
Default phase/capacity policies still run afterward: phases do change despite
zero elapsed flow time. The table concerns the immediate jump, not a claim
that the complete runtime state is frozen. No post-event pressure refresh is

these two preparations under the remaining one-call policies.

**Matched-input control.** Compare remote capacities `(4,4)` and `(2,4)`.
The latter creates real remote pressures `(+2*b,-2*b)`, with `b` the effective
capacity-pressure coefficient. Here `0<2*b<3*a/4`, so both fresh global maxima,
the local rows and local Si agree. The first two executed Dissonance events
then agree as well. Remote capacity contrast has not been silently omitted
from the declared mixed pressure law.

**State-sufficiency consequence.** Let `Q` retain the first component's form,
capacity, phase, support and stored pressure coordinate at the declared event

time. Initial pressure is freshly evaluated; `Q` reads the coordinate without

The [marked occurrence criterion](STRUCTURAL_OPERATORS.md#collective-operator-descent) therefore

If a different observation recomputed pressure immediately after these direct

The realized marks would still differ, but this raw-pressure successor argument

The full stored node records do differ in Si after refresh; retaining that

observations and fixed configuration, `Vmax`
and `Pmax` are sufficient external values for its default base choice alongside

This immediate factorization does not give the maxima their own evolution,

Disconnected transport support alone does not impose locality on a supplied

### A restricted collective map of one native selector batch

The [memory](#native-selector-memory-and-occurrence) and
[environment](#native-selector-environment-inputs) obstructions concern
discarded inputs. Retaining those inputs can admit a collective map on a
restricted family. The following result concerns the actual
`DefaultGlyphSelector` / `_apply_glyphs` path, including its sequential direct
glyphs and live incremental grammar. It installs no new selector or law.

**State and preparation.** Let `B_i={2i,2i+1}`, for `i` modulo five, be the
two-member blocks of the retained doubled-C5 graph. Each adjacent block pair
has all four unit-conductance edges; there are no internal block edges or
external nodes. The two members of block `i` have common signed form
`x_i in [-1,1]`, phase zero, capacity one and zero stored acceleration.
Use the default pressure mixture, diagnostic weights, selector cuts, operator
factors, hard clipping and lag limits. Fix a finite structural clock and the
seed; a primitive batch advances neither clock time nor continuous flow.
The EPI semantic kind (`epi_kind`) is one common nonempty label, retained
unchanged on this family; operator provenance is a separate coordinate.
Freshly evaluate default pressure and Sense Index before preparing the selector.

Retain each block's two lag counts `(a_i,e_i)` and admitted grammar state
`H_i=(history,debt,prior_coherence,operator_step)`, equal within the block,
with nonempty history and debt at most the configured default capacity two.
One sufficient preparation is the supplied `Emission → Coherence → Reception`
context, with zero debt and prior Coherence.
Use strict rejection and the default positive history-retention window.
These records are supplied context, not reconstructed physical history.
The same conclusion holds for subsequent contexts generated by the admitted
branches below. Cache objects, source identifiers and diagnostics are not
additional physical coordinates; every consumed primitive still passes its
shared admission boundary.

**Fresh inputs and realized marks.** Write `k` for the effective normalized
EPI-pressure coefficient and `(alpha,beta,gamma)` for the effective Sense
Index weights. With `P=max_i |p_i|`, the ideal real-arithmetic rows are

```text
p_i = k * ((x_(i-1) + x_(i+1))/2 - x_i)
Vmax = 1
Si_i = alpha + beta + gamma * (1 - |p_i|/P).
```

At `P=0`, use the implemented unit denominator, so the pressure ratio is zero.
The other pressure channels vanish: phases, capacities and degrees agree.
Uniform states are included even when the initial preparation is nonuniform;
hard-clipped Emission can return a uniform endpoint.
The default `alpha+beta` is approximately `0.9417`, above `si_hi=0.5`.
Consequently every base proposal is Coherence, including for nonuniform form.
The selector prepares these inputs before any event; it does not recompute
them between targets. The existing increment-before-comparison policy gives

```text
g_i = AL if a_i >= 5, else EN if e_i >= 3, else IL.
```

Thus Emission takes priority when both limits are due. These are supplied
controller decisions, not consequences of the unforced nodal differential row.
Numerical execution additionally requires all represented input, pressure,
ratio and event arithmetic to be admitted; the ideal formulas do not waive
overflow or underflow rejection.

**Ordered block recurrence.** Process the blocks in the fixed order `0..4`,
with both members of each block consecutive. Initialize `y=x`. At block `i`,
apply exactly one of the following scalar assignments, retaining updates
already made to earlier blocks:

```text
Emission (AL):   y_i <- clip_[−1,1](y_i + b)
Reception (EN):  y_i <- (1-m)*y_i + m*(y_(i-1) + y_(i+1))/2
Coherence (IL):  y_i <- y_i.
```

Here `b`, `m` and `h` are the actual `AL_boost`, `EN_mix` and
`IL_dnfr_factor` settings. Their ideal default expressions are `1/(4*pi)`,
`1/(pi+1)` and `pi/(pi+1)` respectively. The Reception row is a convex blend,
so clipping is inactive for its admitted interval. The raw stored pressure
after the complete batch is

```text
p_i^raw = h*p_i if g_i=IL, else p_i.
```

Phase, capacity, support and structural clock remain fixed on this direct
glyph path. Advance each block's lag pair by the
[existing counter recurrence](#native-selector-memory-and-occurrence).
Append its realized mark once to each member's bounded history, increment
each member's operator step once, and retain the corresponding `source_glyph`.
Emission and Reception leave debt and prior Coherence unchanged; Coherence
maps debt to `max(0,debt-1)` and makes prior Coherence true. The default
preparation therefore retains zero debt and a nonempty trace.

**Proof and admission.** Both members have equal prepared inputs and lag
counts, hence the same proposal. Before their first event, they also have
equal live local grammar and physical coordinates. They are not adjacent:
changing the first member cannot change any neighbor read by the second.
No other target runs between them. Their actual Reception snapshots therefore
have the same form mean and common semantic kind; Emission and Coherence use
the same point maps. After the second event, physical rows, retained grammar,
provenance and counters agree within the block. Induction over the five blocks
gives the displayed recurrence. Both members' U1a checks have a nonempty trace;
debt at most two passes U2, and these three marks require no U3/U4 coupling or
transformer context. Shared numerical and seed admission remains live at each
fine prefix. This establishes a sufficient admitted domain, not unconditional
execution for arbitrary histories or a transactional batch.

The pair-constant family can be left after the first member acts and restored
after the second. The result is an endpoint map of a complete ordered batch,
not descent of every singleton event. In particular, it is not an atomic
frozen-neighbor stage, a five-node invocation of the unchanged native engine,
or a quotient of arbitrary unequal pairs. The observation retains block
labels, the declared multiplicities and target order.

**Raw endpoint versus refreshed return.** Denote the batch by `B` and a
declared pressure-and-Sense-Index refresh by `R`. Generally
`p^raw != p(y)`: an Emission or Reception changes form while retaining stored
pressure; Coherence changes stored pressure while retaining form. Thus `B`
does not return to the freshly prepared pressure submanifold. Its raw output
includes `p^raw` and the unchanged prepared Sense Index. The separately
declared composition `R o B` returns to that submanifold, with pressure given
by the same displayed pressure row evaluated at `y` and newly evaluated Si.
It preserves paired form, phase, capacity, kind, grammar and lag association.
This gives a closed refreshed discrete map on this restricted family's admitted
composition domain, including the refresh arithmetic. It does not turn refresh
into an operator or silently erase the raw event observation.

**Order counterexample.** Set `x=(c,c+1/4,c,c,c)` with `c=1/8`, and make
Reception due in every block while Emission is not due. For contiguous order,
write the first two returned forms as `c+z_0,c+z_1`. The recurrence predicts

```text
z_0 = m/8,
z_1 = (1-m)/4 + m^2/16.
```

A frozen-neighbor simultaneous update would omit the positive `m^2/16`
contribution. Instead interleave the first targets as `(0,2,1,3,4,5,6,7,8,9)`.
After node 0, node 2 already reads one changed member of block 0. Node 1 then
reads that changed node 2. Direct substitution gives the final first-pair gap

```text
x_1^raw - x_0^raw = m^2*(m-8)/128 < 0    for 0 < m <= 1.
```

Neither node acts again, so the pair remains split at the batch endpoint.
The same initial block coordinates, lag counts and grammar do not determine
a pair-constant return when target order is discarded. This scoped failure
does not exclude a larger collective state retaining the generated contrast.

### One complete native step on the synchronized collective family

The [batch result](#native-selector-collective-batch) alone does not cover the
integrator or later native policies. Here the same doubled-C5 preparation is
advanced through one actual `runtime.step`, with default pressure, fresh Sense
Index, the default selector, strict grammar and the default Euler integrator.
The block order and consecutive twins are retained. The live Gamma registry
retains its built-in zero source; its `none` label alone is insufficient.
No custom callbacks or optional mathematics engine run, and the supplied graph history
has no stability-fraction samples admitting automatic REMESH.

**Declared step and state.** Use structural time `t=1`, seed 17 and the explicit
duration `delta=1/16`. This equals the default `DT_MIN`, so preparation selects
exactly one Euler substep; the graph's default `DT=1/2` remains unchanged.
These are declared execution inputs, not a derived physical clock. In addition
to the batch state, retain a prior stored form-rate value `r_i`, a nonnegative
`stable_count` value `s_i` and any consumed temporal history, equal within each
pair. Supplied rates and counts do not certify a past trajectory or stability.
For the finite controls the temporal histories start absent, and the runtime
starts its tracked invocation epoch at zero. The supplied recent grammar trace
contains only Emission, Coherence and Reception; default phase gains and empty
phase histories fix the initial global controller state.

Retain the graph's adaptive phase gains/history, invocation ordinal and REMESH
history separately from node coordinates. Fixed support and node labels allow
the fine-indexed sample and history records to be reconstructed from paired
values. Rebuildable implementation caches are not independent physical state.
This is a factorization of the declared retained observations; it is not a
claim that five scalar forms encode every Python object owned by the runtime.

**Predicted endpoint.** Let `y_i` and `q_i=p_i^raw` denote the actual ordered
batch's form and stored pressure. Let `Si_i` be the fresh pre-batch diagnostic.
The integrator holds the post-glyph pressure and capacity during this substep.
In ideal arithmetic its rows are

```text
z_i = clip_[−1,1](y_i + delta*q_i)
stored_dEPI_i = q_i
stored_d2EPI_i = (q_i-r_i)/delta
t_next = t + delta.
```

The rate and acceleration are integrator telemetry. When clipping is active,
the measured form secant `(z_i-y_i)/delta` need not equal the stored rate.
Nor may `q_i` be replaced by freshly evaluated pressure at `y` or `z`: neither
the integrator nor the subsequent policies perform that constitutive refresh.
The terminal stored pressure remains `q_i`, and stored Si remains `Si_i`.
The separate [continuous and projection contracts](../docs/API_CONTRACTS.md)
retain their own numerical and rate/residual evidence boundaries.

These acceleration rows specifically require one substep. With multiple
constant-pressure Euler substeps, each later substep reads the previous rate
`q_i`, so its terminal acceleration is zero. The default duration `1/2` would
produce eight substeps here. Neither subdivision nor acceleration history can
be silently changed while carrying over this one-step prediction.

**Active phase and capacity policies.** Every phase is zero after the batch
and Euler update. Both global and neighbor phase targets are therefore zero,
so the actual coordinator retains `theta_i=0`. It still evaluates its adaptive
controller and records its gains and phase diagnostics once per invocation.
For the declared Emission/Reception/Coherence histories, order parameter one
and zero disruptor load select its stable branch; each default gain `K` moves
toward its configured lower target by

```text
K_next = K + down*(K_min-K).
```

The existing gain rails still apply. This is an invoked phase relaxation
policy, with no capacity-driven free phase advance and no `delta` multiplier.

The capacity policy reads the retained `Si_i` and `q_i`, not terminal refreshed
fields. Let `eps=EPS_DNFR_STABLE` and `tau=VF_ADAPT_TAU` (default five). Then

```text
eligible_observation_i = (Si_i >= si_hi and |q_i| <= eps)
s_i_next = s_i+1 if eligible_observation_i, else 0
capacity_update_due_i = (s_i_next >= tau).
```

All neighbor capacities and the target capacity equal one. The actual
uniform-fixed-point guard thus keeps `nu_i=1` exactly, even on due nodes.
The policy can execute writes and advance counters without changing capacity.
Equal per-pair counts yield equal successor counts; physical equality alone
does not supply that history condition.

**History and support.** Runtime records the left flow boundary, runs the
batch, then records its right boundary at the same timestamp. A form-changing
event restarts that node's temporal history at `(t,y_i)`. For the declared
empty-history preparation, the completed record is
`((t,y_i),(t+delta,z_i))`, including unchanged-form events. It measures the
post-event interval and cannot absorb the jump into a physical secant.
The terminal graph-wide EPI snapshot is appended once to delayed REMESH
history. This does not supply the separate `stable_frac` history: the actual
automatic REMESH gate remains unavailable and performs no network event.
The admitted invocation advances the ordinal once, independently of the
structural clock and each node's operator step. Support and semantic kinds
remain unchanged on this preparation.

**Preservation and its boundary.** The batch restores paired rows and grammar.
The same pointwise Euler/clipping map then acts on both members; the same
prior rate gives the same acceleration telemetry. Phase zero and capacity one
are fixed points of the invoked policies, and matched counters/history give
matched successor records. Consequently the complete call preserves the
declared paired physical and local bookkeeping observations, while updating
the retained global controller and runtime records. No phase/capacity policy
has been disabled to obtain this result.

A countercontrol gives one member of a qualifying pair `s=tau-1` and the
other `s=0`. Both still finish with capacity one and equal physical rows, but
their successor counts are `tau` and one. The supplied counter association
cannot be discarded from a paired bookkeeping description. This does not
claim a physical splitting of the uniform-capacity pair.

The [full-step controls](../tests/physics/test_native_collective_step.py)
compare an independent rational block/Euler prediction with scalar and NumPy
execution using absolute allowance `1e-14`; exact pair equality, marks and

due and ordinary capacity gates, form clipping, post-jump temporal histories,
phase-controller records, the invocation ordinal and REMESH nonoccurrence.
The prior-rate input is varied by block rather than assumed zero.

This establishes one complete native call on a synchronized restricted family.
Its constant phase and capacity are model-specific fixed points, not a newly
formed collective identity or a demonstration of nontrivial phase/capacity
dynamics. Repeated calls with additional retained history, automatic REMESH,
arbitrary target orders and autonomous selection remain separate admission
questions. The following result admits a nonuniform phase/capacity sector and
identifies a default-selector boundary outside it.
