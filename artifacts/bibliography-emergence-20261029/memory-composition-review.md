Author: `/root/joint_review_controls`, 2026-10-29.

## Assessment and scope

The useful strategic opportunity is to make an organization's predictive state
survive its permitted interactions, while retaining actual initialization and
balance. Three complementary routes are below: response-carrying internal
coordinates, a sufficient interface across continuations/events, and a smaller
dynamic set of nonlinear products. None is presented as the first TNFR memory,
mediator composition, cubic interaction, product-state closure or resonant law:
those already exist. The new target is a useful **source-associated reduction
for a specified response and continuation family**, rather than another generic
projection library or an unrestricted claim of collective autonomy.

## 1. Internal coordinates that preserve a declared response

**Mechanism and bridge.** Printed 19-21 shows that an eliminated coordinate can
produce exponential memory, while an auxiliary first-order coordinate can
represent that memory. Printed 21-24 gives an oscillatory realization from
harmonic coordinates; Appendix 4 organizes response into a coupled chain.
For a declared finite model `y'=Ay+Bh`, `h'=Cy+Dh`, preserve both
`K(t)=B exp(Dt) C` and the source `B exp(Dt) h0`. An exponential term admits a
state `q'=-lambda*q+C*y`, output `B*q`, with its actual source encoded in `q0`.
This is a representation of a supplied generator, not a new pressure law or a
proof that every memory has a small stable realization. The book's general
prose about elimination has the exact-closure exception: discarded coordinates
need not influence the output. Continued-fraction truncation also needs its own
error bound; derive signs from the actual generator/resolvent.

**Already established.** [linear_observation.py](../../src/tnfr/mathematics/linear_observation.py)
already supplies ordered block memory and minimal all-state linear realization
for one fixed admitted generator. [epi_memory.py](../../src/tnfr/physics/epi_memory.py)
adds captured affine sources/offsets; its sampled exponentials are diagnostics,
not certified solution enclosures. [DERIVED_EPI_MEMORY](../../theory/DERIVED_EPI_MEMORY.md)
already proves reversible storage splitting, closure, finite-history examples
and exact realization. A second generic implementation would duplicate this.
[DERIVED_FORM_PHASE](../../theory/nodal/DERIVED_FORM_PHASE.md), section 21.1,
already derives a signed exponential memory and a second-order form equation
from directed first-order nodal flow without added microscopic inertia.

There is also a positive geometry result in
[ORGANIZED_PARENT_RESERVOIR_MEMORY](../../theory/nodal/ORGANIZED_PARENT_RESERVOIR_MEMORY.md):
under its supplied reciprocal auxiliary law, zero-leakage `J=r+c^T theta`
indexes locally attracting registration geometries on invariant leaves. The
specified positive leakage changes the equilibrium classification. This
motivates investigating retained information and geometry; its auxiliary law,
preparation and invariant are not derived from eliminating actual constituents.

**Opportunity and premises.** Identify response-carrying internal coordinates
from an actual organization's complete state and preparation, rather than add
another reservoir or retain only means. Fix boundary input, output, coefficients,
source family, domain and horizon. Reuse the exact row-space construction first.
It may require the full dimension; a smaller count or useful approximation must
be demonstrated. Approximation must bound discarded initialization, kernel and
propagated output error, including any coefficient approximation. The scoped
[acquired-class memory implementation](../../src/tnfr/physics/relational_sine_class_memory.py)
already retains rational spatial blocks and named transcendental factors;
rationalizing those factors would certify a different model unless bounded.

**Minimum future argument/control.** For one actual consumer, establish the
fine-output/memory/augmented-state equivalence and source association. Use equal
visible states with different hidden sources to verify that initialization is
retained. Show a strict state or error advantage; otherwise keep full state.
If the retained state is claimed to select different maintained geometries,
that requires an additional nonlinear result under the same complete law.
**Gain:** a causally meaningful internal NFR state that can carry history into
later response. State-count reduction alone proves no runtime speedup.

## 2. An interface sufficient across a declared family of continuations/events

**Mechanism and bridge.** The harmonic-bath model retains coupling storage before
elimination; chapter 10 explains why resetting/reversing only the observed
coordinate does not reset/reverse the joint state. The constructive comparison
is compose-then-eliminate versus eliminate-with-all-ports-and-source-terms-then-
compose. Equality requires the same joint law, cross-couplings, correlations,
clock and output. A minimal state for isolation can be insufficient when a new
port exposes an old invisible direction. For event `E` and before/after maps,
the existing descent obligation is `Q_plus E = E_bar Q_minus` on the domain.
Equal `Q_minus` with different `Q_plus E` gives a precise handoff obstruction.

**Already established, not proposed as new.**
[RELATIONAL_MEDIATOR_DYNAMICS](../../theory/nodal/RELATIONAL_MEDIATOR_DYNAMICS.md#two-mediator-composition)
already composes two native intermediaries, preserves the inherited field and
storage, gives a wrong-unit-edge control and a joint finite-horizon fast bound
with hidden initial layer. Its static path composition is associative with
length, lift sector and original degrees retained. The
[three-port result](../../theory/nodal/RELATIONAL_MEDIATOR_DYNAMICS.md#three-port-collective-interaction)
already derives non-pairwise interaction: mixed storage first appears at sixth
order, while the actual visible field already has a collective cubic term.
Neither is a missing discovery. Successive static elimination is not by itself
an interchange theorem for finite-capacity dynamics or arbitrary support events.

[COMPOSITION_COMPATIBLE_CONSTITUTIVE_LAWS](../../theory/nodal/COMPOSITION_COMPATIBLE_CONSTITUTIVE_LAWS.md)
already transports both rows, storage, clock, inputs, observations and attachment
work on registered invariant families. Its additive storage constant matters
at attachment even when absent from continuous derivatives. The weighted
[_oriented_interface_constitutive.py](../../src/tnfr/physics/_oriented_interface_constitutive.py)
and [joint_quotient.py](../../src/tnfr/physics/joint_quotient.py) retain distinct
support/degree and held-state premises. The latter does not supply a universal
complete collective state. [DERIVED_FORM_PHASE](../../theory/nodal/DERIVED_FORM_PHASE.md)
already proves fixed-law joint Gram closure criteria, constraints on cross-
relations, and loss of closure when an external source fixes discarded orientation.

[Operator descent](../../theory/STRUCTURAL_OPERATORS.md#collective-operator-descent)
already states the event-fiber criterion, including marks and history.
[_sine_history_continuation.py](../../src/tnfr/physics/_sine_history_continuation.py)
already predicts one fixed continuation from the original packet plus one
contact-history bit without resetting the reached state. This is not an
indefinitely reusable autonomous update. [Event contracts](../../docs/contracts/OPERATOR_EVENTS.md)
and [remesh_history.py](../../src/tnfr/dynamics/remesh_history.py) distinguish
Mutation timestamps, pre-jump REMESH samples and eliminated-state causal memory.
They must not be merged into one generic history channel.

**Opportunity and premises.** Construct a source-associated sufficient interface
for one organization across a finite declared continuation/event family, or
prove exactly what additional state that family needs. This is more specific
than inventing composition or rediscovering descent. Keep actual live port
normalization, event work and initial correlations. A common invariant output
space may help for fixed-support linear continuations; changing support needs
separate spaces and explicit maps. Nonlinear continuations require their own
regularity, residual and identity domain. No generic framework is needed before
one source-specific consumer shows an advantage.

**Minimum future argument/control.** Match the two elimination/composition
orders, their output and full balance for that consumer. Include a same-old-
interface/different-new-port-response pair, then either augment the interface
or bound its ambiguity. Audit continuous loss separately from event storage
jumps; a signed hidden-storage remainder is not a positive reserve and kernel
sign alone does not prove passivity. **Gain:** hierarchy can carry constituent
influence through permitted interactions without microstate resets or silent
loss of information. This would connect predictive identity to its usable
boundaries, rather than to isolated appearance alone.

## 3. Response-specific dynamic products for nonlinear feedback

**Mechanism and bridge.** Printed 160-164 shows that projection of nonlinear
motion moves nonlinear effects into apparent memory. Printed 169-173 selects
products of slow modes when symmetry makes single-mode contributions vanish.
The fluid tail uses its own statistical, hydrodynamic and large-system premises;
its exponents do not transfer to TNFR. The reusable method is to select the
lowest-order products actually consumed by a chosen response.

For deterministic `xi'=A_h xi`, the pointwise product `M=xi xi^T` obeys
`M'=A_h M+M A_h^T`. **M is a deterministic observable, not an ensemble covariance
or statistical moment.** It has realizability constraints inherited from one
fine state. For a fixed admitted tangent, vectorized products form a linear
system on which the existing row-space method can identify the combinations
needed by a specified quadratic output. This only closes the tangent-product
system; it neither closes the original nonlinear law nor guarantees compression.

**Already established.** [ORGANIZED_CONSTITUENT_MEMORY](../../theory/nodal/ORGANIZED_CONSTITUENT_MEMORY.md)
already derives a quadratic interface-variance correction despite zero carrier
tangent memory, the product-state tangent equation, cubic remainder and
same-products/different-nonlinear-response controls. Its form-phase cross terms
matter; phase variances alone do not close. [ORGANIZED_COMPRESSED_MEMORY](../../theory/nodal/ORGANIZED_COMPRESSED_MEMORY.md)
already freezes five initial statistics with bounded drift, while
[ORGANIZED_MEMORY_INITIALIZATION](../../theory/nodal/ORGANIZED_MEMORY_INITIALIZATION.md)
justifies zero estimates for its actual tiny-residual prepared family. Their
successful finite forecast is not a defect that requires dynamic products.

[DERIVED_FORM_PHASE](../../theory/nodal/DERIVED_FORM_PHASE.md), section 21.2,
already has exact deterministic `H=zz^dagger`, `H'=AH+HA^dagger`, rank-at-most-one
positive-semidefinite realizability, joint cross-relations and all-state affine
closure criteria. An ensemble-averaged Gram is explicitly a different object.
[GLOBAL_PULSE_HYPOTHESIS](../../theory/nodal/GLOBAL_PULSE_HYPOTHESIS.md#free-collective-pulse-interaction),
sections 14-15, already derives the complete resonant amplitude interaction,
three band actions, collective back reaction and finite reconstruction; it
also proves a bounded linear counterpropagating response with a new slow
frequency, without claiming nonlinear all-time stability. Products, symmetry
selection and resonant nonlinear coupling are therefore established methods.
Their conservative model/normal form does not supply a reduction for the
different dissipative, moving-carrier source.

**Opportunity and premises.** Only if a useful response resolves evolving hidden
feedback, derive a *proper response-specific subset* of deterministic products
with propagated nonlinear error, instead of freezing statistics or carrying the
entire product matrix. Select the first nonzero output term and its true symmetry.
Use fixed-generator closure only when the tangent is fixed. A moving carrier
requires its time-dependent coefficients or a proved common retained subspace;
freezing them silently changes the approximation. Preserve realizable source
products and all consumed form-phase associations. Finite accuracy, not an
unproved exact nonlinear quotient, is the plausible target.

**Minimum future argument/control.** Prove a strict product-state reduction,
propagate the known cubic/higher remainder and compare against the already
successful static forecast under one common source, input and horizon. Use
existing equal-variance/different-derivative and opposite-hidden-state controls
to expose missing cross terms and discarded cubic information. If no useful
error/cost gain remains, stop. **Gain:** an interpretable intermediate state
explaining delayed collective response through specific internal associations,
without claiming the first mode-coupling mechanism or adding a statistical axiom.

## Choice, limits and open questions

Composition-compatible predictive state has the clearest strategic payoff;
exact internal realization supplies its first tools. Dynamic product reduction
is a conditional refinement when nonlinear feedback is actually consequential.
The book's finite-lattice corrections (printed 24-29, 193-197) also suggest
checking the observation horizon: finite conservative environments can return
information that an infinite-bath approximation loses. TNFR's genuine dissipative
loss must not be relabeled as dephasing, and no recurrence/entropy law follows
from this analogy. Retain the actual complete generator and finite boundaries.

The next selection should ask: which boundary response must the organization
predict; across which admitted interactions; with what available initial
information; and whether a smaller state preserves that response and full
balance at useful accuracy. None of these proposals changes the current queue,
selects a universal constitutive law or opens physical mapping. Their value is
a possible improvement in the foundations of organized objects and composition.
