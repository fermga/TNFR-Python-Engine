## How to read byte associations

The retained records bind **raw original bytes**, including original line
endings. The selected `artifacts/` files are therefore stored without Git text
normalization. The maintained `NATIVE_FOUNDATIONAL_ACCOUNT.md`, which is
directly bound by the current prerequisite reviews, requires the same rule.
Do not normalize or reformat frozen files to repair a failed digest.

A historical receipt may refer to a maintained owner that has since changed.
Its original source is resolved by the matching path and SHA-256 inside the
associated frozen source ZIP. The current checkout is not a substitute for
those historical bytes. Source archives preserve the original producing code,
models, reviews and selected inputs. One producing archive includes the small
historical `.venv313/pyvenv.cfg` metadata file; no Python environment, cache or
third-party book is included.

Some original receipts also refer to local repository-wide preservation
inventories, documentation-build logs or temporary synthetic fixtures. Those
are not published here. `excluded_receipt_dependencies` identifies deliberately
omitted JSON-receipt dependencies; the selection does not claim that every
historical bookkeeping script can run from this checkout. Independent review
texts may additionally cite earlier context outside this selected package.
No frozen manifest has been rewritten to conceal those boundaries.

`public-receipt-audit.json` records a first repository-relative receipt pass;
`public-receipt-context.json` resolves its attempt-relative paths and preserved
renamed drafts. The final selection adds the exact older physical-assessment
chapter in `native-access-literature-20261029/before-edit.zip`. Two old native
adapter/test formatting hashes are explicitly superseded by the already
retained `mathematical-format-review.json`; the revised source bytes are
preserved. These are content associations, not fresh scientific approvals.

## Scope and execution

Source archives, executable scripts and consumed prospective protocols are
historical evidence, not a standing instruction or authorization to execute
another study. The current `theory/RESEARCH_PROGRAM.md` and `AGENTS.md` own
research selection and prospective admission. Local Windows paths and runtime
observations describe the original execution; they are not portable runtime
guarantees or authentication of provenance.

The four reviewed foundation resolutions retain their limited mathematical
domains. The current physical-mapping readiness record remains `null`.
Publishing an old exact-task readiness review does not reactivate its former
documentary inquiry, authorize a new physical mapping, or establish empirical
validation.

The ordinary documentation/CI prerequisite check consumes only the current
four reviews and their declared chapter evidence. Passing that check does not
verify all research results or every file in this larger selection.

Bookkeeping-only publication checks may compare bytes, archive members and
retained associations. They must not replay a trajectory, target solve,
scientific producer, diagnostic or failed attempt to make publication pass.
