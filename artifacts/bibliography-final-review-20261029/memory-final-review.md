Author: `/root/joint_review_controls`; 2026-10-29.

## Decision and independence boundary

The proposed generic priority, "a reusable predictive internal state across
interactions", is too broad to identify a missing result. The repository already
contains exact fixed-law linear realizations, exact collective interaction
criteria, finite flow/event composition, a bounded record carried through an
actual contact, nonlinear port memory, and a component substitution theorem
under feedback. These are positive achievements, not merely warnings about
closure. They should be linked together rather than rediscovered or wrapped in
a new generic API.

The smallest useful new consumer is the current **actual formed source to
two-port joint organization** admission. Its new content is the actual source,
event, identity and future-response association. Full state is an acceptable
predictive reference. A smaller retained state is an optional optimization,
conditional on an independently useful cost/error advantage for that consumer.
It is not a prerequisite that should delay source/identity admission.

This is a read-only conceptual/source audit, not a new proof review or scientific
evaluation. I authored the earlier `memory-composition-review.md`; that own
contribution is not independent evidence for its proposals. This pass checked
those proposals against additional canonical owners and current planning. No
maintained source, scientific producer, trajectory, numerical rank assessment,
or evaluated prediction was changed or executed. Parent-owned baseline and
consolidation controls remain separate.

## Exact, approximate, or impossible: one classification contract

For a fixed linear model, output-Krylov stabilization is already implemented.
For several admitted fixed linear modes on one node space, the elementary
extension is to require a row space containing the requested output rows and
invariant under every consumed generator and reset. In a common chart (C),
the identities would be

\[
 C J_s=G_s C,\qquad C R_e=M_e C,\qquad O_s=D_s C.
\]

Known affine inputs/reset offsets project separately. The event selector,
clock, input metadata and admissibility must also be available to the retained
description. These identities explain the test; this audit did **not** compute
a common row space or implement a multi-mode extension. The existing fixed-J
API must not be described as already accepting arbitrary switched families.
Conversely, stating this elementary extension is not a new emergence result.

A common invariant space is sufficient for arbitrary admitted repetitions; it
can be larger than necessary for one bounded chronological word. A finite
history packet and a dynamically updated reduced state are different objects.
Minimality is always relative to the allowed source set, output, action family
and representation class. The fixed-J all-state linear minimum does not prove
the minimum number of nonlinear coordinates, bits or history entries.

For nonlinear flow or a nonlinear observation, reuse the existing fiber test:
fine states identified by a candidate description must have identical declared
future outputs under every allowed continuation. Exact autonomous reduction
also needs the retained rate and each event image to be well-defined on those
fibers. Storage and event work, if consumed, add obligations; an output-row
realization alone need not determine their quadratic/nonlinear values.

| Classification | Required conclusion for the actual consumer | Stop condition |
| --- | --- | --- |
| Exact reduced state | Prove flow, input and event descent, initialization and each requested observation on the admitted family. Keep realizability and any gauge choice. | Accept the realization, including a full-state answer; do not chase smaller dimension without a declared gain. |
| Controlled approximation | Bound all admitted sources and consumed histories over one fixed horizon, including discarded initialization, changed coefficients, nonlinear remainder and event mismatch/work. Compare with the same complete law. | Accept only if the resulting uncertainty resolves the chosen discrimination and improves a declared cost. No improvement means keep the existing reference. |
| Impossible **for this description and accuracy** | Exhibit two admissible fine states/histories with the same retained record and a future separation exceeding twice the allowed point-prediction error. | Add the specifically exposed information, allow a justified set-valued prediction, or abandon this compression. Do not generalize to impossibility of all smaller states. |
| Not yet classified | The source image, action association, observation or error margin is missing. | Record the missing premise. No parameter/tolerance/endpoint search substitutes for admission. |

Existing Gram ambiguity and history-bit witnesses already instantiate the
third row. They do not transfer numerical bounds to the current two-port source.
In particular, failure of an isolated quotient says nothing by itself about a
useful finite-error forecast; a successful approximate forecast says nothing by
itself about exact closed state dynamics.

## Smallest new consumer: one source, one contact event, two continuations

Use precisely the current [program](../../theory/RESEARCH_PROGRAM.md): donor
class two and receiver class one at their actual isolated formation images,
before the historical one-bridge event. Keep the inherited relative phase
origin, full error correlations, local ordering, phase lifts, capacities and
clock. Compare unchanged disconnected continuation with insertion of the two
declared edges `4--4` and `5--5`, followed by unchanged complete sine dynamics.
No removal/reinsertion, source reset, new law family or arbitrary future event
word is needed to make this a useful new consumer.

The distinction from the existing results is precise:

- The one-bridge formed-source result establishes its own finite interaction;
  it does not supply the proposed two-port organization or its event budget.
- Two-port compatibility establishes an internally deformed target and local
  recovery. The capture certificate uses a different midpoint-aligned source.
  Its eight-coordinate folded **auxiliary slow reference** is not an exact
  eight-coordinate closure of the actual thirty-six-coordinate source family.
- The proposed handoff preserves the actual formation image and its inherited
  phase origin. Showing its new organization, or establishing a precise
  admission obstruction, adds a generative association rather than another
  example of eliminated coordinates.

The complete 36-coordinate state plus the fixed metadata is a sufficient
dynamical reference; this does not assert exact numerical integration or
minimal dimension. Common gauges may be removed only with the same observation
and means accounted for. Post-contact component means must not be held fixed.
The new degrees are three at the four ports and two elsewhere in both rows.

Start with the required internal-arc deformation observation, defined on the
same labeled constituents before and after the event and in the disconnected
control. A candidate pair is the donor and receiver short-arc deviations from
their isolated twists, expressed in the inherited continuous lifts. This is
only a candidate observation, not an admitted identity threshold, source-entry
proof or predictive separation. The current task must justify its membership
domain and initial-absence margin and one conditional relational-response test.
Failure to admit those is a valid stopping outcome before any transit.

Source state, event work, identity and future response belong in one declaration.
Work includes both newly inserted edges, evaluated on the actual preevent state;
the old one-edge allowance and prior dissipation are not its funding premise.
The contact event leaves coordinates continuous but changes the consumed degree
normalization and weighted-mean accounting. A compact record must preserve
whatever this declaration consumes, not only a convenient current mean.

Only after these obligations identify an actual computational bottleneck should
a smaller state be considered. Reuse exact observation/memory for a justified
fixed tangent, or an existing source-specific nonlinear residual method for the
complete law. Prove that this new interface/source meets that method's premises.
Do not import the one-bridge reduced-port coefficients or the midpoint folded
reference. The storage-only handoff obstruction already rules out repeating
that particular acute-boundary certificate; it does not rule out actual
same-law entry by another justified route.
